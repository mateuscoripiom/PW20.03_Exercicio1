# Exercício de Programação Web -- C# (ASP.NET MVC)

🇧🇷 Exercício introdutório de ASP.NET MVC: demonstra roteamento entre actions, ViewBag/TempData para passar dados entre requisicoes, e redirecionamento externo -- sem lógica de negocio real, e um exercício de mecânica do padrão MVC.

🇬🇧 Introductory ASP.NET MVC exercise: demonstrates routing between actions, ViewBag/TempData for passing data across requests, and external redirects -- no real business logic, it's an exercise in the mechanics of the MVC pattern itself.

**Stack:** C#, ASP.NET MVC
**Contexto:** provável exercício da época técnica (ETEC, 2021-2023).
